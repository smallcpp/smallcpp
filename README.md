# smallcpp

Initial C++ CMake scaffold. The `shell` target is a hello-world program.

## Build

```sh
cmake -S . -B build
cmake --build build
./build/shell
```

## Layout

- `src/shell` — shell executable
- `src/compiler` — source directory for a later target
- `src/preprocessor` — source directory for a later target
- `docs` — documentation
- `scripts` — helper scripts
- `tests` — tests
- `tests/examples` — example inputs
